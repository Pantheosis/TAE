`sefstars.txt` is the Swiss Ephemeris fixed-star catalogue (Astrodienst; the file's own header records its provenance and editing history), copied UNMODIFIED on 2026-09-11 from the `kerykeion` package (version 5.12.9, `kerykeion/sweph/sefstars.txt`), which redistributes it under AGPL-3.0 -- the licence this app carries (`LICENSE`). It is the only ephemeris file shipped: the planets stay on the built-in Moshier ephemeris (no `.se1` file is bundled or needed); the app links this file alone into a private directory before pointing `swe.set_ephe_path` at it (see `_fixed_star_catalogue_ready` in `app.py` and `BUILD_NOTES.md`).
